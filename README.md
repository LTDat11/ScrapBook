# ScrapBook

[![Kotlin](https://img.shields.io/badge/Kotlin-2.3.20-blue.svg)](https://kotlinlang.org)
[![Compose](https://img.shields.io/badge/Jetpack%20Compose-2026.03.01-green.svg)](https://developer.android.com/jetpack/compose)
[![Platform](https://img.shields.io/badge/Platform-Android-brightgreen.svg)](https://www.android.com)

**ScrapBook** is a modern Android application designed to transform your precious moments into creative digital stamps.

## Tech Stack

- **Language:** [Kotlin](https://kotlinlang.org/)
- **UI Framework:** [Jetpack Compose](https://developer.android.com/jetpack/compose)
- **Asynchronous:** Coroutines & Flow
- **State Management:** ViewModel & StateFlow
- **Image Loading:** [Coil](https://coil-kt.github.io/coil/)
- **Design System:** Material 3
